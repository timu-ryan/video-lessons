# Слайды для видеоуроков испанского

Приложение для записи экрана в OBS. Слайд рисуется в фиксированном холсте
1920×1080 и целиком масштабируется под окно (letterbox), поэтому все размеры
в коде — пиксели макета, а не экрана. Правый нижний угол 520×380 всегда пуст:
там камера.

```bash
npm install
npm run dev        # http://localhost:5173/ — список уроков
```

Запись: открыть на весь экран (клавиша **F**), окно докладчика (**P**) вывести
на второй монитор и не захватывать в OBS.

## Клавиши

| Клавиша | Действие |
|---|---|
| → / Space / PageDown | следующий шаг, затем следующий слайд |
| ← / PageUp | шаг назад (на предыдущий слайд — в раскрытом виде) |
| Home / End | первый / последний слайд |
| T | транскрипция вкл/выкл |
| R | перевод вкл/выкл (слайды «проверь себя») |
| F | полный экран |
| G | рамка зоны камеры (только для проверки) |
| B | полоска прогресса внизу |
| P | окно докладчика |
| Esc | назад к списку уроков (в полном экране — только выход из него) |

PageUp/PageDown — чтобы работал обычный презентационный кликер. Буквы
отслеживаются по физической клавише, так что русская раскладка не мешает.
Курсор исчезает через 1,5 с бездействия, никакого интерфейса в кадре нет.

Позиция сохраняется в адресе: `#/lesson/10/12/3` — урок, слайд, шаг. После
перезагрузки открывается тот же шаг. Настройки T/R/G/B лежат в localStorage.

По пустому адресу (`/`) открывается список уроков: он собирается из тех же
файлов `lessons/lesson-NN.json`, так что новый урок появляется в нём сам.

## Структура

```
lessons/           уроки: lesson-10.json, …
src/features/
├── slides/        движок: холст, навигация, шаги, клавиши, типы слайдов
│   └── views/     по компоненту на тип слайда
├── lessons/       форма файла урока, проверка, вычисляемые поля, реестр
├── presenter/     второе окно, синхронизация через BroadcastChannel
└── settings/      T/R/G/B в localStorage
```

Контент отделён от компонентов полностью и лежит вне кода: урок — это файл
`lessons/lesson-NN.json` с массивом слайдов, размеченным дискриминированным
union по полю `type`. Текст, который произносишь за кадром, лежит в поле
`notes` — он идёт только в окно докладчика; объяснение словами живёт там,
а не на слайде.

| type | что на слайде | шаги |
|---|---|---|
| `title` | курс, тема, оглавление | 1 |
| `section` | номер и название раздела | 1 |
| `table` | новые слова и фразы, до 5 строк, `ipa` обязательна | строка за шаг |
| `rule` | формула (`["quiero", "+", "инфинитив"]`), пояснение, до 3 примеров | формула, потом пример за шаг |
| `conjugation` | глагол, до 6 строк «местоимение · основа+**окончание** · перевод» | строка за шаг |
| `compare` | две колонки, до 3 пар: ser / estar, по-русски / по-испански, `tone: wrong/right` | пара за шаг |
| `practice` | задание (+ `hint`) → пауза → ответ (+ `alternatives`) | 2 |
| `dialogue` | реплики говорящих | реплика за шаг |
| `final` | итоги и следующий урок | пункт за шаг |

Полная форма каждого типа с комментариями — в `features/lessons/source.ts`.

### Нумерация и метаданные

`number` — сквозной номер в курсе (1–84), он же в имени файла. `level` (`A0`…`B2`)
и `planLesson` — адрес урока в плане: «A1, урок 3». Пара `level` + `planLesson`
не должна повторяться — это проверяется при загрузке.

`newVocabulary` (`es`, `ru`, `pos`) и `newGrammar` на слайды не выводятся:
из них `npm run vocab:build` собирает `docs/vocabulary.md` и заодно предупреждает,
если слово введено как новое в двух уроках.

### Выделение нового

Прямо в строке: `"Quiero **aprender** español."` — выделенное подсвечивается
цветом. Работает в `es` и `ru` любых фраз и в `alternatives`. Незакрытые `**`
падают при загрузке.

**Новый урок** = новый файл `lessons/lesson-NN.json`. Реестр находит его сам
по имени, номер урока берётся оттуда же (`lesson-07.json` → `"number": 7`).
Ни компоненты, ни `registry.ts` трогать не нужно.

### В файле нет ничего вычисляемого

Это главное правило формата: урок пишется и генерируется так, чтобы вставка
одной фразы в середину ничего не ломала. Поэтому в JSON **нет**

| | считается по |
|---|---|
| номера практики (`1/16`) | порядку слайдов практики |
| `1/2` у разрезанного раздела | подряд идущим слайдам с тем же заголовком |
| названия раздела на каждом слайде | ближайшему предыдущему `section` |
| номера разделов | порядку разделов |
| оглавления на титуле | названиям всех разделов |
| курса, темы и «Урок N» на титуле | метаданным урока |
| длительности паузы в практике | `pauseMs` слайда → `pauseMs` группы → длине испанской фразы, если ни там, ни там не задано |
| цветов говорящих | порядку в `speakers` |
| `id` слайда | типу и номеру, если не задан явно |

Всё это появляется в `features/lessons/derive.ts` — единственном месте, где
живёт арифметика урока. Поэтому типов два слоя: `lessons/source.ts` описывает
то, что лежит в файле, а `slides/types.ts` — то, что получают компоненты, уже
с заполненными полями.

Одна фраза — один тип: `es`, `ru`, `ipa`. Он же строка таблицы,
пример правила, задание практики (`ru` — задание, `es` с `ipa` — ответ), реплика
диалога (плюс `speaker`). В строке спряжения `es` не пишется — собирается
из `stem` и `ending`. Перевод нигде не дублируется.

Подписи колонок таблиц лежат в `tableHeaders` урока, на слайде — только
переопределение, можно частичное (`"headers": { "es": "Вопрос" }`).

JSON компилятор не проверяет, поэтому при загрузке урок прогоняется через
`features/lessons/parse.ts`: чужой `schemaVersion`, неизвестный `type`,
`level` или `tone`, пропущенное поле, дубль `id` слайда,
говорящий не из `speakers`, группа практики не из `practiceGroups`, шестая
строка в таблице или седьмая в спряжении, незакрытое `**` — всё это падает сразу и с адресом (файл → слайд → поле), а не рисует пустой
слайд.

## Транскрипция

Поле `ipa` обязательно в строках `table` на любом уровне (это новые слова)
и во всех фразах уроков `A0` (это уроки про произношение). В остальных местах
оно необязательно: орфография почти фонетическая, а транскрипция длинного
предложения ученику мало что даёт.

Запись — Международный фонетический алфавит (МФА / IPA), кастильская норма,
фонемная (широкая):

| | |
|---|---|
| `ˈ` | перед ударным слогом |
| `θ` | c перед e, i и z — `ˈgɾaθjas` (в Латинской Америке `s`) |
| `j` | ll и y — `ˈkomo te ˈjamas` |
| `x` | j и g перед e, i |
| `ɾ` / `r` | одиночное r / начальное r и rr |
| `b` `d` `g` | смычные везде, в том числе между гласными: `enkanˈtado` |
| `.` | только там, где зияние: `ˈdi.as` |

Смычные — сознательное упрощение: между гласными они звучат как аппроксиманты
(`enkanˈtaðo`, `ˈbiβes`), но для курса с нуля это лишний уровень точности.
Чтобы новые уроки не сползали к более узкой записи, `npm run check:slides`
проверяет, что `β ð ɣ ʎ` в файлах не встречаются. Конвенция целиком записана
в шапке `features/lessons/source.ts` — там её видит и генератор.

В Manrope нет ни одного знака МФА — даже ударения, — поэтому строки
транскрипции набираются шрифтом из переменной `--font-ipa` (`src/index.css`).
Иначе браузер подставлял бы запасной шрифт по одному глифу и строка выходила
бы сборной.

## Тема

Вся палитра — CSS-переменные в начале `src/index.css`. Тем две: `sand`
(светлая, по умолчанию) и `night` (тёмная). Переключается полем `theme`
в настройках; чтобы сменить палитру, достаточно переопределить переменные —
компоненты цветов не знают.

## Проверка вёрстки

```bash
npm run dev              # в одном терминале
npm run check:slides     # в другом
```

Скрипт проверяет конвенцию транскрипции по файлам уроков, а затем прогоняет
каждый слайд и каждый шаг во всех сочетаниях T/R: ничего не заезжает в зону
камеры, нет текста мельче 32px, ничего не вылезает за холст. `--shots`
дополнительно складывает скриншоты слайдов в `.shots/`. Полезно после
добавления нового урока.
