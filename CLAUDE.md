# Проект: слайды для видеокурса «Испанский с нуля»

Приложение показывает уроки из `lessons/lesson-NN.json` как презентацию для
записи видео. Уроки не пишутся вручную: они собираются из утверждённых
сценариев `scenarios/lesson-NN.md`.

## Ключевые файлы

| Файл | Что это |
|---|---|
| `docs/lessons-guide.md` | Справочник формата JSON урока. Источник правды по полям, лимитам, IPA. |
| `docs/lesson-script-format.md` | Формат сценария `.md` и соответствие его блоков слайдам. |
| `docs/course-plan.md` | План курса A0–B1: что изучается в каждом уроке. |
| `docs/vocabulary.md` | Накопленный словарь. **Генерируется**, руками не править. |
| `scenarios/lesson-10.md` + `lessons/lesson-10.json` | Эталонная пара «сценарий → JSON». |
| `src/features/lessons/parse.ts` | Валидация урока при загрузке. |

## Нумерация

`number` — сквозной номер урока. A0 — уроки 1–14, A1 — 15–39, A2 — 40–64,
B1 — 65–84. `planLesson` — номер внутри уровня по плану. Имя файла —
`lesson-NN.json` с ведущим нулём до двух цифр.

## Как собрать урок из сценария

Запускается командой `/lesson NN` или просьбой «собери урок NN».

1. Прочитай `scenarios/lesson-NN.md`, `docs/lesson-script-format.md`,
   `docs/lessons-guide.md` и эталон `lessons/lesson-10.json`.
2. Сверь шапку с `docs/course-plan.md`: `level` и `planLesson` соответствуют
   `number`, тема и грамматика совпадают с пунктом плана. Расхождение —
   сообщи, не исправляй молча.
3. Перенеси сценарий в `lessons/lesson-NN.json` один в один.
4. Добавь то, чего нет в сценарии:
   - `schemaVersion: 3`, `course: "Испанский с нуля"`,
     `tableHeaders: { "es": "Испанский", "ru": "Перевод" }`;
   - `practiceGroups` — по заголовкам блоков `practice`, в порядке появления,
     без `pauseMs`;
   - `ipa` по конвенции раздела 8 справочника: в `table` всегда, на A0 — также
     в `rule`, `conjugation`, `practice`. Кастильская широкая запись, никаких
     `β ð ɣ ʎ`.
   - `ipa` в `newVocabulary` — только у слов, которые не встречаются
     отдельным словом во фразах урока с `ipa` (инфинитив, который на слайдах
     только спряжён). Остальное конспект найдёт сам; `npm run lessons:pdf -- NN`
     предупредит о пропусках.
5. Механически можно только: резать `table` больше 5 строк и `dialogue`
   больше 4 реплик на слайды с тем же заголовком. **Содержание не менять**:
   не переписывать фразы, не сокращать, не добавлять задания и реплики.
6. Если сценарий нарушает правила, которые механически не исправить (длинная
   фраза, 4 примера в `rule`, группа практики без заданий, неизвестный
   `speaker`, неоднозначная фраза без подсказки), не угадывай. Собери всё
   остальное и перечисли проблемы в отчёте с цитатами из сценария.
7. Запусти проверки:
   - `npm run lessons:validate` — должен пройти без ошибок; если падает на
     собранном файле, исправь JSON;
   - `npm run vocab:build` — пересобирает `docs/vocabulary.md`;
   - `npm run vocab:check -- NN` — предупреждения о словах, которые не были
     введены раньше.
8. Отчёт пользователю, кратко:
   - файл собран / не собран, число слайдов и заданий практики;
   - проблемы сценария (п. 6);
   - предупреждения `vocab:check` с твоей оценкой: реальная проблема или
     ложная тревога (форма известного глагола, имя собственное);
   - все транскрипции `ipa` из `table` списком «es — ipa» для быстрой
     проверки глазами;
   - напоминание: «Обновите docs/vocabulary.md в проекте Claude».

## Прочее

- Эталонный урок 10 создан раньше уроков 1–9. Его `newVocabulary` честный:
  при подготовке уроков 1–9 его слова не считаются изученными.
  Предупреждения `vocab:check -- 10` о словах уроков 1–9 ожидаемы.
- `docs/vocabulary.md` меняется только через `npm run vocab:build`.
- Изменения схемы урока (новые поля, типы слайдов) — сначала в `parse.ts`
  и `docs/lessons-guide.md`, затем в эталоне и формате сценария.
- PDF-конспекты для учеников (PDF в git; `--html` сохраняет HTML для отладки):
  - полный: `/notes NN` или `npm run lessons:pdf -- NN` →
    `handouts/free|paid/lesson-NN.pdf`;
  - краткий (выжимка на 1 страницу, из блока `summary`): `/summary NN` или
    `npm run lessons:summary -- [NN] [--ipa]` → `handouts/free/lesson-NN-summary.pdf`.
  - Граница бесплатного и ссылки — `scripts/handouts.config.ts`.
- Код в стиле проекта: TypeScript.
