# Как писать уроки для приложения слайдов

Это справочник для того, кто генерирует файлы уроков. Урок — один JSON-файл.
Приложение само превращает его в презентацию для записи видео. Если файл
соответствует этому справочнику, он откроется без правок кода.

Уроки не пишутся вручную: они собираются из утверждённых сценариев
`scenarios/lesson-NN.md` (команда `/lesson NN`, порядок — в `CLAUDE.md`).
Формат сценария и соответствие его блоков слайдам описаны
в `docs/lesson-script-format.md`.

## 1. Что это за приложение

Слайды для видеоуроков испанского для русскоязычных учеников. Автор записывает
экран в OBS и говорит за кадром. Камера с его лицом стоит в правом нижнем углу.

- Холст 1920×1080. Правый нижний угол 520×380 всегда пуст: там камера.
- Слайды открываются по шагам: строки таблицы по одной, ответ в практике после паузы и так далее.
- Клавиша **T** включает и выключает транскрипцию, **R** — перевод. Урок должен
  читаться в любом сочетании.
- Второе окно (окно докладчика) видит только автор. В нём текст из поля
  `notes` — то, что автор говорит за кадром.

## 2. Главные правила

1. **Один урок — один файл** `lessons/lesson-NN.json`, где NN — сквозной номер
   урока (`lesson-15.json`). Больше ничего добавлять не нужно.
2. **В файле нет ничего, что можно вычислить.** Не пишите номера практики
   («3/16»), номера разделов, «1/2», название раздела на слайде, оглавление,
   цвета, `id`. Всё это приложение считает само по порядку слайдов.
3. **Файл проверяется при загрузке.** Пропущенное обязательное поле, лишняя
   строка в таблице, неизвестный `type` — и урок не откроется, а в ошибке будет
   адрес: файл → слайд → поле.
4. **Объяснение — словами, в `notes`.** Слайд показывает материал: слова,
   формулу, примеры. Рассуждения и пояснения автор говорит вслух.
5. Поля, которых нет в этом справочнике, приложение молча игнорирует. На них
   нельзя рассчитывать: они не появятся на экране.

## 3. Верхний уровень файла

```json
{
  "schemaVersion": 3,
  "number": 15,
  "level": "A1",
  "planLesson": 3,
  "title": "Хочу, могу, нужно",
  "course": "Испанский с нуля",
  "newVocabulary": [{ "es": "aprender", "ru": "учить, выучить", "pos": "verb" }],
  "newGrammar": ["quiero / puedo / necesito + инфинитив"],
  "speakers": { "ana": "Ana", "carlos": "Carlos" },
  "tableHeaders": { "es": "Испанский", "ru": "Значение" },
  "practiceGroups": [
    { "name": "Разминка", "pauseMs": 4000 },
    { "name": "Основная практика" }
  ],
  "slides": []
}
```

| Поле | Обяз. | Что это |
|---|---|---|
| `schemaVersion` | да | Всегда `3`. |
| `number` | да | Сквозной номер урока в курсе, 1–84. Совпадает с номером в имени файла. |
| `level` | да | `A0`, `A1`, `A2`, `B1` или `B2`. |
| `planLesson` | да | Номер урока внутри уровня, как в плане курса («A1, урок 3» → `3`). Пара `level` + `planLesson` не должна повторяться в разных файлах. |
| `title` | да | Тема урока. Выводится на титульный слайд. |
| `course` | да | Название курса. Выводится на титульный слайд. |
| `newVocabulary` | желательно | Слова, которые урок вводит **впервые**: `{ es, ru, pos }`. На экран не выводятся, из них собирается словарь курса. |
| `newGrammar` | желательно | Конструкции, которые урок вводит впервые: массив строк. |
| `speakers` | да | Персонажи диалогов: ключ → имя. Цвета назначаются по порядку. Если диалогов нет — `{}`. |
| `tableHeaders` | да | Подписи колонок таблиц по умолчанию: `{ es, ru }`. |
| `practiceGroups` | да | Группы практики: `name` и необязательный `pauseMs` (см. раздел 7). Если практики нет — `[]`. |
| `slides` | да | Непустой массив слайдов. |

**`newVocabulary`:**
- `es` пишите в словарной форме: инфинитив, существительное с артиклем (`"el año"`).
- `ipa` — необязательна: транскрипция словарной формы для PDF-конспекта.
  Пишите её, только если слово не встречается отдельным словом во фразах
  урока с `ipa` — обычно это инфинитив, который на слайдах только спряжён.
  Иначе конспект возьмёт транскрипцию из фраз сам.
- `pos` — одно из значений: `noun`, `verb`, `adj`, `adv`, `pron`, `prep`,
  `conj`, `art`, `num`, `interj`, `phrase` (готовое выражение вроде
  `"¿Qué tal?"`).
- Слово, которое уже было новым в прошлом уроке, сюда не включайте: скрипт
  сборки словаря предупредит о повторе.

## 4. Общие для всех слайдов поля

| Поле | Что это |
|---|---|
| `type` | Тип слайда, обязателен. |
| `notes` | Массив строк: текст, который автор говорит за кадром, дословно или близко к тому. Сюда же служебные пометки (`🎥 КАМЕРА`, `⏱ 2:15–3:45`, `🔊`). На слайд не выводятся. |
| `id` | Необязателен; указывайте только если он нужен. Если задан, не должен повторяться. |

## 5. Фраза

Большинство слайдов состоят из фраз. У фразы одна и та же форма:

```json
{ "es": "Quiero **aprender** español.", "ru": "Я хочу выучить испанский.", "ipa": "ˈkjeɾo apɾenˈdeɾ espaˈɲol" }
```

- `es` — испанский, `ru` — перевод. Оба обязательны, если не сказано иное.
- `ipa` — транскрипция. Где она обязательна — в разделе 8.

### Выделение нового: `**…**`

То, на что зритель должен обратить внимание, выделяйте прямо в строке:
`"Quiero **aprender** español."`. Приложение подсветит выделенное цветом.

- Работает в `es` и `ru` фраз (таблица, пример правила, практика, реплика
  диалога, пункт сравнения) и в `alternatives`.
- Звёздочки всегда парные, вложенных выделений нет. Незакрытое `**` — ошибка
  загрузки.
- Не работает в заголовках, `hint`, `text`, `label`, `pattern`: там звёздочки
  выведутся как есть.
- Выделяйте мало: новое слово, окончание, предлог, отличие. Если выделено
  полфразы, выделения не видно.

## 6. Типы слайдов

Ограничения по количеству ниже проверяются при загрузке. Длина текста не
проверяется, но длинная строка переносится и съедает место (см. раздел 9).

### `title` — титульный слайд

```json
{ "type": "title", "notes": ["🎥 КАМЕРА", "«Привет! Сегодня…»"] }
```

Курс, «Урок N», тему и оглавление приложение берёт само: оглавление собирается
из заголовков всех `section`. Необязательное `agenda: string[]` заменяет
оглавление. Первый слайд урока.

### `section` — заголовок раздела

```json
{ "type": "section", "title": "Хочу + инфинитив", "hint": "Второй глагол не меняется" }
```

Номер раздела ставится сам. `hint` — подпись под заголовком, до 2–3 коротких
предложений. Название раздела выводится в шапке всех следующих слайдов до
следующего `section`.

### `table` — новые слова и фразы

```json
{
  "type": "table",
  "title": "Три глагола",
  "headers": { "ru": "Перевод" },
  "rows": [
    { "es": "quiero", "ru": "я хочу", "ipa": "ˈkjeɾo" }
  ]
}
```

- От 1 до **5** строк, `ipa` обязательна в каждой строке на любом уровне.
- Строки открываются по одной.
- `headers` необязателен и может переопределять подпись только одной колонки.
- Больше пяти строк — делайте несколько `table` подряд с **одинаковым**
  `title`: приложение само поставит «1/2», «2/2».

### `rule` — правило: формула и примеры

```json
{
  "type": "rule",
  "title": "Хочу + инфинитив",
  "pattern": ["quiero", "+", "инфинитив"],
  "text": "Меняется только первый глагол — как в русском «хочу говорить».",
  "examples": [
    { "es": "Quiero **aprender** español.", "ru": "Я хочу выучить испанский." }
  ]
}
```

- `pattern` — элементы формулы. `"+"` рисуется знаком. Испанское слово — залитой
  плашкой. Элемент на кириллице («инфинитив», «существительное») — пустой
  рамкой, то есть местом для подстановки. Держите формулу в 2–5 элементах.
- `text` — необязательное пояснение, 1–2 строки.
- `examples` — от 1 до **3** фраз.
- Шаги: сначала формула с пояснением, затем примеры по одному.

### `conjugation` — спряжение

```json
{
  "type": "conjugation",
  "verb": "querer",
  "ru": "хотеть",
  "rows": [
    { "pronoun": "yo", "stem": "quier", "ending": "o", "ru": "я хочу" },
    { "pronoun": "nosotros / nosotras", "stem": "quer", "ending": "emos", "ru": "мы хотим" }
  ]
}
```

- От 1 до **6** строк, открываются по одной.
- `stem` + `ending` = форма. Окончание подсвечивается. `es` не пишите:
  он собирается сам.
- У полностью неправильной формы `stem` может быть пустой строкой, тогда
  подсвечена вся форма: `{ "pronoun": "yo", "stem": "", "ending": "soy", … }`.
  Пустыми сразу оба поля быть не могут.
- `pronoun` может быть длинным (`"él / ella / usted"`) — он переносится.
- `ru` обязателен. `ipa` — как у фразы.
- Заголовок слайда: «querer — хотеть».

### `compare` — сравнение в две колонки

Для всего, что понимается через противопоставление: ser / estar,
perfecto / indefinido, «по-русски / по-испански», неверно / верно.

```json
{
  "type": "compare",
  "title": "ser или estar",
  "left":  { "label": "ser — какой вообще",  "items": [{ "es": "Es **aburrido**.", "ru": "Он скучный." }] },
  "right": { "label": "estar — как сейчас", "items": [{ "es": "Está **aburrido**.", "ru": "Ему скучно." }] }
}
```

- В каждой колонке от 1 до **3** пунктов. Пункты идут **парами по строкам**:
  `left.items[0]` стоит напротив `right.items[0]`. Шаг открывает одну строку.
- У пункта `ru` **необязателен**: у неверного варианта перевода обычно нет.
- `tone` у колонки необязателен:
  - `"wrong"` — ✗, красная подпись, фразы зачёркнуты;
  - `"right"` — ✓, зелёная подпись;
  - без `tone` — равноправные колонки разного цвета, без оценки.
- В колонке «по-русски» русский текст пишется в поле `es`: это основной текст
  пункта.
- Разбор ошибки делайте так:
  ```json
  {
    "type": "compare",
    "title": "Спрягается только первый глагол",
    "left":  { "label": "так не говорят", "tone": "wrong", "items": [{ "es": "Quiero **aprendo** español." }] },
    "right": { "label": "так говорят",    "tone": "right", "items": [{ "es": "Quiero **aprender** español.", "ru": "Я хочу выучить испанский." }] }
  }
  ```

### `practice` — «переведи вслух»

Одно задание — один слайд. Зритель видит русскую фразу и полоску паузы, говорит
вслух, затем появляется испанский ответ.

```json
{
  "type": "practice",
  "group": "Основная практика",
  "phrase": {
    "ru": "Вы говорите по-английски?",
    "hint": "вежливо",
    "es": "¿Usted habla inglés?",
    "alternatives": ["¿Habla usted inglés?"]
  }
}
```

- `group` — имя из `practiceGroups`, ровно как там. Название группы выводится
  в углу слайда.
- `hint` — уточнение, без которого перевод неоднозначен: «вежливо», «девушке»,
  «неформально», «во множественном числе». Скобки приложение ставит само.
  **Пишите `hint` всегда, когда русская фраза допускает несколько разных
  ответов**: ты / вы, род, число.
- `alternatives` — до **2** других правильных ответов. Нужны, когда зритель
  может сказать иначе и тоже верно: «Hablo español» и «Yo hablo español».
  Показываются под ответом строкой «или …».
- `pauseMs` на самом слайде необязателен (см. раздел 7).
- Держите `es` до ~60 символов, `ru` до ~70.

### `dialogue` — диалог

```json
{
  "type": "dialogue",
  "title": "В кафе",
  "lines": [
    { "speaker": "ana", "es": "¿Qué **quieres** tomar?", "ru": "Что ты хочешь выпить?" }
  ]
}
```

- `speaker` — ключ из `speakers`.
- Реплики открываются по одной. **Не больше 4 реплик на слайд.** Длинный
  диалог режьте на слайды с одинаковым `title` — появится «1/2».
- `ipa` у реплик на экран не выводится, писать её не нужно.

### `final` — финальный слайд

```json
{
  "type": "final",
  "title": "Теперь вы умеете",
  "bullets": ["Говорить, что вы хотите сделать: quiero + инфинитив"],
  "nextTitle": "Следующий урок",
  "nextText": "Урок 16: прошлое время — что вы делали вчера",
  "outro": "¡Hasta luego!"
}
```

`bullets` открываются по одному, лучше 3–5 пунктов. `outro` необязателен.
Последний слайд урока.

## 7. Паузы в практике

Длительность паузы перед ответом берётся по первому заданному источнику:

1. `pauseMs` у самого слайда `practice`;
2. `pauseMs` у группы в `practiceGroups`;
3. иначе считается автоматически по длине испанского ответа:
   2500 мс + 600 мс на слово, от 3000 до 12000 мс.

Рекомендация: **не задавайте `pauseMs` у группы**, пусть пауза считается сама.
Тогда короткое «Trabajo mucho» не ждёт столько же, сколько длинная фраза.
Задавайте `pauseMs` явно, только если пауза нужна намеренно длиннее
или короче.

## 8. Транскрипция `ipa`

**Когда обязательна:**
- в каждой строке `table` на любом уровне: это новые слова;
- в уроках уровня `A0` — во всех фразах, где она предусмотрена: `table`, примеры
  `rule`, строки `conjugation`, `practice`. Уроки A0 — про произношение.

**Где не нужна:** начиная с A1 — в практике, примерах, спряжении и сравнении,
а в диалогах — никогда (там она не выводится). Длинную фразу транскрибировать
не стоит: пользы ученику мало, а ошибиться легко.

**Конвенция записи** — МФА, кастильская норма, фонемная (широкая) запись:

| Знак | Когда |
|---|---|
| `ˈ` | перед ударным слогом: `ˈkjeɾo` |
| `θ` | c перед e, i и буква z: `ˈgɾaθjas` |
| `j` | ll и y: `ˈkomo te ˈjamas` |
| `x` | j, а также g перед e, i |
| `ɾ` / `r` | одиночное r / начальное r и rr |
| `b d g` | смычные **везде**, в том числе между гласными: `enkanˈtado`, `ˈbibes` |
| `.` | только при зиянии: `ˈdi.as` |
| ` · ` | граница предложений внутри одной фразы: `ˈola · ke ˈtal` |

**Запрещены** `β ð ɣ ʎ` — это узкая запись, проверка на них падает.
В транскрипции не бывает `**`.

## 9. Ограничения вёрстки

Слайд должен помещаться в холст, не залезая в угол камеры. Количество строк
проверяется при загрузке, а длина текста — нет. Ориентиры:

| Где | Ориентир |
|---|---|
| `title` слайдов `table`, `rule`, `conjugation`, `compare`, `dialogue` | до ~25 символов, не переносится. Вместе с названием раздела — до ~50. |
| `section.title` | до ~35 символов |
| `table`: `es` / `ru` | до ~30 / ~35 символов |
| `rule`: `examples[].es` | до ~45 символов |
| `compare`: `items[].es` | до ~25 символов: колонка узкая |
| `conjugation`: `ru` | до ~25 символов |
| `practice`: `es` / `ru` | до ~60 / ~70 символов |
| `dialogue`: `es` | до ~50 символов, до 4 реплик на слайд |

Если материала больше, делите на два слайда, а не удлиняйте один.

## 10. Типичная структура урока

```
title
section  → table (новые слова) → rule (как ими пользоваться) → conjugation (если есть новый глагол)
section  → table / compare (контраст, типичная ошибка)
section «Практика» (hint: как проходить практику)
practice × 25–40, в 3–4 группах от простого к сложному
section «Мини-диалог» → dialogue × 1–3
final
```

Методические правила:
- Новое слово впервые появляется в `table`: с транскрипцией, переводом и
  выделением, если нужно. Затем оно попадает в `newVocabulary`.
- Грамматика показывается через `rule`. Спряжение — через `conjugation`, а не
  через `table`. Противопоставление — через `compare`.
- В практике и диалогах используйте только слова, которые уже изучены: в этом
  или прошлых уроках.
- У каждого задания практики ровно один ожидаемый ответ. Если их несколько —
  добавьте `hint`, `alternatives` или то и другое.
- `notes` — полный текст за кадром. На каждый содержательный слайд — хотя бы
  одна реплика автора.

## 11. Чек-лист перед сдачей файла

- [ ] Имя файла `lesson-NN.json` совпадает с `number`, `schemaVersion` = 3.
- [ ] Заданы `level` и `planLesson`, пара не совпадает с другим уроком.
- [ ] `title` — первый слайд, `final` — последний.
- [ ] В `table` не больше 5 строк, и в каждой есть `ipa`.
- [ ] В `rule` не больше 3 примеров, в `conjugation` не больше 6 строк,
      в `compare` не больше 3 пунктов в колонке, в `alternatives` не больше 2.
- [ ] Уровень A0: `ipa` во всех фразах `table`, `rule`, `conjugation`, `practice`.
- [ ] Каждая группа из `practice.group` описана в `practiceGroups`, каждый
      `speaker` — в `speakers`.
- [ ] Все `**` парные.
- [ ] В `ipa` нет `β ð ɣ ʎ`.
- [ ] Нет вычисляемых полей: номеров, «1/2», названий разделов на слайдах.
- [ ] Заполнены `newVocabulary` и `newGrammar`.

## 12. Полный пример урока

Эталонный урок — пара файлов:
