# Формат сценария урока (scenarios/lesson-NN.md)

Сценарий — это утверждённый текст урока, из которого Claude Code собирает
`lessons/lesson-NN.json`. Сценарии пишутся в проекте Claude (чат) и кладутся
в репозиторий как есть.

Главный принцип: **один блок `##` — один слайд** (кроме `practice`, где один
пункт списка — один слайд). В сценарии есть весь содержательный текст урока.
Claude Code ничего не придумывает: он только переносит, добавляет `ipa`
и режет слишком большие блоки по правилам `docs/lessons-guide.md`.

Эталон: `scenarios/lesson-10.md` → `lessons/lesson-10.json`.

## Шапка

```yaml
---
number: 10            # сквозной номер урока, совпадает с именем файла
level: A0
planLesson: 10        # номер урока внутри уровня по docs/course-plan.md
title: Глаголы на -er и -ir
speakers:             # если диалогов нет — speakers: {}
  ana: Ana
  carlos: Carlos
newVocabulary:        # слова, которые урок вводит ВПЕРВЫЕ: es — ru (pos)
  - vivir — жить (verb)
  - el café — кофе (noun)
newGrammar:
  - настоящее время глаголов на -er
---
```

`pos`: noun, verb, adj, adv, pron, prep, conj, art, num, interj, phrase.

## Общие правила записи

| Запись | Значение |
|---|---|
| `## тип` или `## тип: заголовок` | начало слайда |
| `ключ: значение` | поле слайда |
| `- …` | строка / пример / пункт / задание |
| `> …` | одна реплика автора за кадром (один элемент `notes`) |
| `es — ru` | фраза: испанский, длинное тире с пробелами, русский |
| `**…**` | выделение нового, как в JSON |

В сценарии **не пишутся**: `ipa`, `course`, `schemaVersion`, `tableHeaders`,
номера, «1/2».

## Слайды

### title
```
## title
> 🎥 КАМЕРА
> «Привет! Сегодня…»
```
Необязательно: `agenda:` и пункты `- …` под ним.

### section
```
## section: Глаголы на -er
hint: Отбрасываем -er и добавляем окончание
> «…»
```

### table (1–5 строк)
```
## table: Новые глаголы на -er
- Quiero **beber**. — Я хочу пить.
- **Vendo** un coche. — Я продаю машину.
> «Beber — пить…»
```
Необязательно: `headers.es: …` или `headers.ru: …`.
Больше 5 строк — Claude Code разобьёт на слайды с тем же заголовком.

### rule (1–3 примера)
```
## rule: Хочу + инфинитив
pattern: quiero | + | инфинитив
text: Меняется только первый глагол.
- Quiero **aprender** español. — Я хочу выучить испанский.
```

### conjugation (1–6 строк)
```
## conjugation: comer — есть
- yo | com·o | я ем
- él / ella / usted | com·e | он, она ест; вы едите
```
Формат строки: `местоимение | основа·окончание | перевод`.
Полностью неправильная форма: `- yo | ·soy | я есть`.

### compare (1–3 пары)
```
## compare: Типичная ошибка
left [wrong]: так не говорят
right [right]: так говорят
- Nosotros **vivemos**. || Nosotros **vivimos**. — Мы живём.
```
Одна строка `- …` — одна пара «левый || правый». Перевод у пункта
необязателен. Метка `[wrong]` / `[right]` необязательна; без неё колонки
равноправные.

### practice (один пункт — один слайд)
```
## practice: Глаголы на -er
- Я много ем. → Como mucho. | Yo como mucho.
- Вы пьёте пиво? [вежливо, одному человеку] → ¿Usted bebe cerveza? | ¿Bebe usted cerveza?
```
Формат: `русский [подсказка] → испанский | вариант | вариант`.
Заголовок блока — имя группы. Несколько блоков подряд — несколько групп
в порядке появления. Реплика `>` сразу под пунктом относится к этому заданию.
Необязательная явная пауза: `{pause: 8000}` в конце строки.

### dialogue (до 4 реплик на слайд)
```
## dialogue: Где ты живёшь?
- carlos: ¿**Vives** en Moscú? — Ты живёшь в Москве?
- ana: No, **vivo** en Madrid. ¿Y tú? — Нет, я живу в Мадриде. А ты?
```
Длинный диалог лучше сразу писать несколькими блоками с одинаковым
заголовком. Если в блоке больше 4 реплик, Claude Code разрежет его сам,
а реплики `>` поставит на первый слайд.

### final
```
## final: Теперь вы умеете
- Спрягать глаголы на -er
- Говорить, где что происходит: en + место
next: Урок 11: вопросы — qué, dónde, cuándo, por qué
outro: ¡Adiós!
> «…»
```
Необязательно: `nextTitle:` (по умолчанию «Следующий урок»).

## Требования к содержанию (для автора сценария)

- Урок соответствует своему пункту в `docs/course-plan.md`.
- Новое слово впервые появляется в `table` — внутри короткого предложения,
  а не отдельным словом — и записывается в `newVocabulary`.
- В практике, примерах и диалогах — только слова из `docs/vocabulary.md`
  (уроки с меньшим номером) и новые слова этого урока.
- Практика: 25–40 заданий в 3–4 группах, от простого к сложному, примерно
  60–70% опираются на старый материал.
- Если русская фраза допускает разные ответы (ты / вы / vosotros, род, число) —
  подсказка `[…]`. Если верны несколько переводов — варианты через `|`.
- Лимиты длины — раздел 9 `docs/lessons-guide.md`.
- На каждый содержательный слайд — хотя бы одна реплика `>`.
