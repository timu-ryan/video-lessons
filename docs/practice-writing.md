# Как писать практический урок

Инструкция для автора `scenarios/practice-NN.md` (команда `/practice N`).

Практический урок — без теории и без новых слов: зритель переводит вслух
фразы из уже пройденного. Синтаксис блоков — `docs/lesson-script-format.md`.
Голос, реплики, подсказки и перевод — как в обычном уроке, разделы 4–6
`docs/scenario-writing.md`. Здесь только то, чем практика отличается.

## 1. Что это и где стоит

- **Отдельная серия.** Файлы `scenarios/practice-NN.md` → `lessons/practice-NN.json`,
  NN — сквозной номер практики (1, 2, 3…), а не урока. Номера уроков не
  меняются: уроки уже опубликованы.
- **`afterLesson`** — после какого урока практика стоит в плейлисте и в
  приложении. Известно всё из уроков с номером ≤ `afterLesson`.
- **`planLesson`** — номер практики внутри уровня: «Практика 1 (A0)».
- **Расписание** — в `docs/course-plan.md`, таблица «Практические уроки» в конце
  уровня: после какого урока, какие уроки закрепляет, на что обратить внимание.
- **В приложении** — адрес `#/lesson/p1`, в списке сразу после своего урока,
  на титуле «Практика 1».
- **Где ставить на новом уровне:** после тематического блока из 3–5 уроков.
  Граница блока — там, где следующий урок открывает новую тему, а не
  продолжает старую. Расписание уровня добавь в план до первого сценария
  практики и согласуй с автором курса.

## 2. Порядок работы

1. Аргумент — номер практики N. Найди её строку в таблице «Практические уроки»
   плана: `afterLesson`, уроки блока (from–to), «особое внимание». Отступление
   от плана по пожеланию автора назови в отчёте.
2. Остановись и скажи об этом, если:
   - `scenarios/practice-NN.md` уже есть: не перезаписывай без прямой просьбы;
   - нет `lessons/lesson-<afterLesson>.json`: словарь неполон.
3. Прочитай:
   - `docs/lesson-script-format.md`;
   - разделы 4–6 `docs/scenario-writing.md` и этот файл;
   - `docs/vocabulary.md`: известно только то, что введено в уроках
     ≤ `afterLesson`;
   - `docs/story.md`;
   - сценарии уроков блока целиком: их практика, примеры, диалоги и
     «Типичные ошибки» — это материал, который закрепляем;
   - сценарий прошлой практики, если он есть: каркас и голос.

   **Не читай `extras/` и `handouts/`**, как и в обычном уроке.
4. Запусти `npm run practice:gaps -- <from>-<to>`: грамматика блока, слова блока,
   которые почти не звучали в речи, и забытые слова прошлых уроков.
5. Напиши сценарий, проведи вычитку (раздел 7), исправь найденное.
6. `docs/story.md` не меняй: практика сюжет не двигает.
7. Дай отчёт (раздел 9). `/lesson pN` не запускай: сценарий сначала
   утверждает автор курса.

## 3. Каркас

```
title
section: Разминка        → practice: Разминка (8–10)
section: <тема блока>    → practice: <тема> (8–10)      × 2–3, по темам блока
section: Вперемешку      → practice: Вперемешку (12–15)
section: Рассказ         → practice: Рассказ (6–8)  → text (тот же рассказ)
section: Диалог          → practice: Диалог (6–8)   → dialogue × 2 (тот же диалог)
final
```

Слайды — только `title`, `section`, `practice`, `text`, `dialogue`, `final`.
`table`, `rule`, `conjugation`, `compare` в практике нет: это теория,
`parse.ts` такой файл не пропустит.

| Что | Значение |
|---|---|
| Заданий `practice` | 50–65, видео ≈ 12–15 минут |
| Новых слов | 0 |
| Дословно из уроков блока | не больше ~10% заданий |
| Материал прошлых блоков | около трети «Вперемешку» и связной речи |

Если блок маленький и заданий выходит больше 65, убери «Рассказ» или «Диалог»,
но не оба: связная речь нужна в каждой практике.

### Шапка

```yaml
---
kind: practice
number: 1             # сквозной номер практики, совпадает с именем файла
level: A0
planLesson: 1         # номер практики внутри уровня
afterLesson: 4        # после какого урока стоит
title: Я и ты: хочу, могу, собираюсь   # дословно из плана
speakers:
  ana: Ana
  carlos: Carlos
---
```

`newVocabulary` и `newGrammar` нет.

### Служебные блоки

```
## title
> 🎥 КАМЕРА
> «Привет! Сегодня урок без нового — только практика по урокам 1–4: <что повторим, 2–4 пункта>.»
> «После этой практики вы будете <конкретное действие> быстрее и увереннее.»
```

Первый раздел объясняет, как проходить практику, — дословно:

```
## section: Разминка
hint: Фраза по-русски → пауза → скажите вслух по-испански
> «Начнём с разминки. Вы видите фразу по-русски — пока идёт полоска, скажите её вслух по-испански. Потом появится ответ. Не бойтесь ошибиться: главное — говорить.»
```

Остальные `section`: заголовок до ~35 символов, `hint` — что тренируем:
`quiero, puedo, necesito + инфинитив`. Реплика — 1–2: что сейчас будет и
напоминание правила одной фразой со ссылкой на урок: «Помните, после quiero
глагол не меняется: quiero comer. Это урок 3.» Нового объяснения нет. Если без
объяснения не обойтись, тема не готова для практики: её место в уроке.

```
## final: Что мы повторили
- Говорить, что вы хотите и можете: quiero, puedo + инфинитив
next: Урок 5: он, мы, они — все лица
outro: ¡Hasta luego!
> 🎥 КАМЕРА
> «<что зритель теперь говорит увереннее>»
> «Если какой-то блок дался трудно, вернитесь к уроку <N> и пройдите практику ещё раз.»
> «В следующем уроке <тема урока afterLesson + 1>. ¡Hasta luego!»
```

- 3–5 пунктов: по теме на пункт, глагол с заглавной буквы, испанские примеры
  после двоеточия.
- `next` — урок `afterLesson + 1`, как в обычном `final`.

## 4. Отбор материала

- **Только пройденное.** Слова — из `docs/vocabulary.md` до `afterLesson`,
  включая испанский в репликах. Грамматика — только из уроков ≤ `afterLesson`.
  Осторожно с русским прошедшим временем до уроков о прошедшем.
- **Каждая тема блока.** На каждую строку `newGrammar` уроков блока —
  не меньше 4 заданий. Темы — примерно поровну, а не по их объёму в уроке.
  Больше — там, где у урока была «Типичная ошибка».
- **Забытые слова.** Каждое слово блока из `practice:gaps` с 0–1 употреблением —
  хотя бы в одном задании; с 2 — по возможности. Забытые слова прошлых уроков —
  в «Вперемешку» и связную речь.
- **Все лица.** Каждое лицо, пройденное к `afterLesson`, — хотя бы в 2 заданиях,
  vosotros и usted тоже. Подсказки — как в разделе 6 `docs/scenario-writing.md`.
- **Новые сочетания, а не копии.** Та же конструкция с другими словами, другим
  лицом, с отрицанием, вопросом. Иначе зритель вспоминает ответ, а не строит
  фразу. Дословно из уроков блока — только ключевые фразы, до ~10% заданий.
- **Ловушки.** На каждую «Типичную ошибку» уроков блока — 2–3 задания, где её
  легко сделать: «Мне нравится читать», где тянет сказать yo gusto. Без пометки.
- **От простого к сложному.** Разминка — 1–4 слова, формы и короткие фразы. Темы —
  4–8 слов. «Вперемешку» и связная речь — две части, вопрос и ответ, связки
  y, pero, porque.
- **Выделение `**`.** В `practice` его нет, как в уроках. В `text` и `dialogue`
  выделены формы, ради которых блок, и связки.
- Длина фраз, подсказки и варианты — раздел 6 `docs/scenario-writing.md`, лимиты —
  раздел 9 `docs/lessons-guide.md`.

## 5. Связная речь

Зритель сначала говорит текст сам, по фразам, а потом слушает его целиком.

**Рассказ.** 6–8 предложений одной истории, от первого лица героя или
«о себе». Группа `practice: Рассказ` — предложения по порядку, по одному на
задание. Затем `## text:` с теми же предложениями дословно:

```
## text: Рассказ Карлоса
- …
> «А теперь весь рассказ целиком.»
> 🔊 Прочитать рассказ целиком.
```

**Диалог.** 6–8 реплик. Группа `practice: Диалог` — все реплики по порядку,
у каждой подсказка с именем: `[Ана]`, `[Карлос]`. Затем два блока `dialogue` с
одинаковым заголовком и теми же репликами дословно; первая реплика — «🔊
Проиграть диалог целиком, потом по репликам.», как в разделе 7
`docs/scenario-writing.md`.

**Герои.** Факты — только из канона `docs/story.md` по урокам ≤ `afterLesson`;
нового о героях не добавляем, сюжет не двигаем. До урока 9 канон не устоялся:
берём сцену без биографии — планы на завтра, желания, что нравится.

## 6. Реплики

- `title` и `final` — с `🎥 КАМЕРА`.
- `section` — 1–2 реплики (раздел 3).
- `practice` — 0–2 реплики на блок, только под трудным заданием:
  «Помните: tengo que — с que.»
- `text` и `dialogue` — 🔊 и одна реплика.
- Всё остальное — раздел 4 `docs/scenario-writing.md`.

## 7. Вычитка

Как в разделе 8 `docs/scenario-writing.md`: отдельный агент с чистым
контекстом, только путь к сценарию и список файлов из шага 3 раздела 2. Он
ничего не правит и отвечает списком находок с цитатами. Проверяет:

1. **Испанский:** грамматика, ударения, `¿ ¡`, род и согласование, живая ли
   фраза, испанский ли Испании.
2. **Перевод:** совпадает ли со смыслом и формой фразы.
3. **Опережение:** слова и грамматика уроков после `afterLesson`, в том числе
   в репликах.
4. **Нового нет:** каждое слово есть в `docs/vocabulary.md` до `afterLesson`.
5. **Покрытие:** каждая тема блока — от 4 заданий; слова с 0–1 употреблением из
   `practice:gaps` задействованы; все лица.
6. **Повторы:** задания, дословно взятые из уроков блока, — сколько и какие.
7. **Практика:** неоднозначные задания без подсказки, неполные или неверные
   варианты.
8. **Каркас:** раздел 3, дословные блоки, `text` и `dialogue` совпадают с
   заданиями своей группы, лимиты длины.
9. **Герои:** нет противоречий с `docs/story.md` и нет новых фактов.

Явные ошибки исправь сам. Спорное не решай: вынеси в отчёт.

## 8. Сборка JSON

`/lesson pN` — по разделу «Как собрать урок из сценария» в `CLAUDE.md`,
с отличиями:

- файлы: `scenarios/practice-NN.md` → `lessons/practice-NN.json`;
- в JSON: `kind: "practice"`, `number`, `level`, `planLesson`, `afterLesson`;
  `newVocabulary` и `newGrammar` нет; остальное (`schemaVersion`, `course`,
  `tableHeaders`, `practiceGroups`) — как в уроке;
- сверка — со строкой таблицы «Практические уроки» плана;
- `ipa` — по правилам уровня: на A0 — в каждом `practice`;
- проверки: `npm run lessons:validate`, `npm run vocab:check -- pN`,
  `npm run check:slides -- --lesson=pN` (без ведущего нуля). `vocab:build` не
  нужен: новых слов нет.

## 9. Отчёт

Кратко:

- путь к файлу; число блоков, реплик, заданий по группам;
- покрытие: тема блока → число заданий; слова из `practice:gaps` с 0–1
  употреблением — какие задействованы, какие нет и почему;
- сколько заданий дословно из уроков;
- что нашла вычитка и что исправлено; спорные места с цитатами;
- следующий шаг: прочитать, поправить, затем `/lesson pN`.

Если автор курса вносит правку общего характера, предложи записать её сюда.
