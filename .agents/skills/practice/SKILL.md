## Вызов и параметры

Вызов: `$practice N [пожелания]`.

Первое слово — номер практики, остальной текст — необязательные пожелания; квадратные скобки обозначают необязательную часть и не входят в параметры.

`$ARGUMENTS` в инструкциях ниже — параметры из запроса пользователя (при явном вызове — текст после имени Skill). Подставляй их в команды и пути вместо `$ARGUMENTS`. Все пути отсчитываются от корня проекта.

## Инструкции

Напиши сценарий практического урока: $ARGUMENTS. Первое слово — номер практики, остальное — необязательные пожелания.

Номер дополни ведущим нулём до двух цифр: результат `scenarios/practice-NN.md`.

Действуй строго по `docs/practice-writing.md`: строка практики в плане, проверки
перед началом, чтение только нужных файлов (без `extras/` и `handouts/`),
`npm run practice:gaps`, сценарий, независимая вычитка, затем краткий отчёт.
`docs/story.md` не меняй.

`$lesson pN` не запускай: сценарий сначала утверждает автор курса.
