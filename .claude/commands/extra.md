Собери дополнительные материалы к уроку номер $ARGUMENTS: платный PDF для подписчиков.

Формат файла и лимиты — раздел 14 `docs/lessons-guide.md`. Номер дополни
ведущим нулём до двух цифр: `extras/lesson-NN.json`.

1. Прочитай `lessons/lesson-NN.json`, `docs/vocabulary.md`, пункт урока N
   и 3–4 следующих в `docs/course-plan.md`, `extras/` предыдущих уроков
   (продолжение истории, какие выражения и виды заметок уже были). Если урока
   нет или он не проходит `npm run lessons:validate` — скажи и остановись.
2. Если `extras/lesson-NN.json` уже есть — не сочиняй заново, переходи к шагу 5
   (если пользователь не просит переписать).
3. Составь `extras/lesson-NN.json` по правилам содержания ниже и запиши его.
4. `npm run lessons:validate` — исправь ошибки. `npm run vocab:check -- NN`,
   раздел «Доп. материалы»: незнакомое слово **исправь**, переписав фразу —
   это наш текст, не сценарий. Ложные тревоги (форма известного глагола,
   имя) оставь и назови в отчёте.
5. `npm run lessons:extra -- NN`. Если скрипт предупредил о повторе фразы
   урока — замени задание; о лишних страницах — сократи практику или историю.
6. Переименуй `handouts/paid/lesson-NN-extra.pdf` →
   `handouts/paid/Урок N — дополнительные материалы.pdf` (N — без ведущего
   нуля; если старый файл в git — `git mv -f`), старый `lesson-NN-extra.pdf`
   не оставляй.
7. Отчёт кратко:
   - путь к PDF, число страниц (`pdfinfo`), задания по видам;
   - выражения списком «es — ipa — ru»;
   - заметка «Испания изнутри» целиком — **на проверку фактов**;
   - итог `vocab:check` для допматериалов с оценкой ложных тревог.

## Правила содержания

**Словарь.** Только слова уроков ≤ N (`docs/vocabulary.md` и таблицы уроков) +
выражения допматериалов ≤ N + не больше 2 слов в `glossary` истории. Имена —
из `tools/vocab-ignore.txt`. Испанский Испании, с vosotros.

**Новизна.** Никаких дословных повторов фраз урока и выжимки — новые
предложения на ту же грамматику. `lessons:extra` ловит точные совпадения.

**Практика.** Все четыре вида, если урок их позволяет: `translate`, `fix`,
`gap`, `read` (на уроке про звуки `fix` и `gap` можно пропустить).
- ~60% заданий — тема урока, ~40% — повторение прошлых, особенно 2–3
  последних уроков. Внутри блока — от простого к сложному.
- `fix`: одна ошибка на фразу; ошибки — типичные для русскоязычных
  и из слайдов `compare` с `tone`. В `es` выдели исправленное, в `why` —
  почему, коротко.
- `gap`: ровно один верный ответ. Если без перевода неоднозначно — дай `ru`.
- `translate`: где перевод неоднозначен — `hint` («вежливо», «девушке»),
  другие верные ответы — в `alternatives`.

**Интересно, а не учебниково.** Жизненные ситуации и юмор: «не люблю рано
вставать», «люблю есть, но не готовить», а не «я читаю книгу». Ана и Карлос —
с теми характерами, что в диалогах уроков; история продолжается из урока
в урок (прочитай прошлые `story`).

**Живые выражения.** 2–4, частые в Испании, связаны с темой и грамматикой
урока, без грубостей. Если выражение по плану вводится позже — в `note`
«подробно — в уроке X». Если в Латинской Америке говорят иначе — отметь.
Пример — только на известных словах плюс само выражение.

**Испания изнутри.** Одна заметка: пословица, скороговорка, факт о быте или
песня по теме. Только то, в чём уверен, без выдуманных цифр и дат.
У песни — название и исполнитель, текст не цитируй дальше названия. Вид
заметки не повторяй два урока подряд; на уроках про звуки — скороговорка.

**Ваш ход.** Открытое задание по итогу урока (см. слайд `final`), шаблон
начал фраз и образец ответа. Никаких «пришлите голосовое» и «пишите в чат» —
чата нет.

**Транскрипция.** `ipa` — по разделу 8 справочника, кастильская широкая
запись, без `β ð ɣ ʎ`. Обязательна у выражений, у пословицы и скороговорки,
на A0 — у фраз с характером.
