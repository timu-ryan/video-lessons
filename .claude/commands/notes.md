Собери PDF-конспекты урока номер $ARGUMENTS: полный и краткий, как у урока 1.

1. Запусти `npm run lessons:pdf -- $ARGUMENTS`. Если урок не найден или не
   прошёл проверку — покажи ошибку и остановись.
2. Если скрипт предупредил «нет произношения», добавь `ipa` этим словам
   в `newVocabulary` урока (кастильская широкая запись, как в разделе 8
   `docs/lessons-guide.md`, без `β ð ɣ ʎ`), запусти `npm run lessons:validate`
   и собери конспект заново.
3. Краткий конспект — по `.claude/commands/summary.md`: если в уроке нет блока
   `summary`, составь его, покажи и спроси, записать ли; затем
   `npm run lessons:validate` и `npm run lessons:summary -- $ARGUMENTS`.
   Если скрипт написал «выжимка заняла 2 стр.» — не переименовывай её,
   а предложи сокращения по шагу 3 `summary.md`.
4. Переименуй результаты (N — номер урока без ведущего нуля), старые
   `lesson-NN*.pdf` не оставляй; для файлов в git — `git mv -f`:
   - `handouts/free|paid/lesson-NN.pdf` → `Урок N — полный конспект.pdf`
     в той же папке;
   - `handouts/free/lesson-NN-summary.pdf` →
     `handouts/free/Урок N — краткий конспект.pdf`.
5. Отчёт кратко: пути к обоим PDF, число страниц каждого (`pdfinfo`), какие
   `ipa` добавлены в урок — списком «es — ipa» для проверки глазами.
