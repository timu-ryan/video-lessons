Собери PDF-конспект урока номер $ARGUMENTS.

1. Запусти `npm run lessons:pdf -- $ARGUMENTS`. Если урок не найден или не
   прошёл проверку — покажи ошибку и остановись.
2. Если скрипт предупредил «нет произношения», добавь `ipa` этим словам
   в `newVocabulary` урока (кастильская широкая запись, как в разделе 8
   `docs/lessons-guide.md`, без `β ð ɣ ʎ`), запусти `npm run lessons:validate`
   и собери конспект заново.
3. Отчёт кратко: путь к PDF, число страниц (`pdfinfo`), какие `ipa` добавлены
   в урок — списком «es — ipa» для проверки глазами.
