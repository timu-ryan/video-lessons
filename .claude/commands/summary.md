Собери краткий конспект (выжимку) урока номер $ARGUMENTS.

Формат блока `summary` — раздел 13 `docs/lessons-guide.md`.

1. Если в `lessons/lesson-NN.json` нет блока `summary` — составь его по уроку:
   6–10 ключевых фраз из таблиц (с `ipa` оттуда же), главное правило в 2–3
   строки, одна типичная ошибка (обычно из слайда `compare` с `tone`),
   3–5 заданий из практики урока, лучше из группы «Всё вместе». Фразы и
   задания бери из урока как есть, не переписывай. Покажи блок и спроси,
   записать ли его, прежде чем менять файл.
2. `npm run lessons:validate`, затем `npm run lessons:summary -- $ARGUMENTS`.
3. Если выжимка не уместилась на страницу — предложи, что сократить
   (меньше фраз, короче правило), не меняя вёрстку.
4. Отчёт кратко: путь к PDF, что вошло в выжимку.
