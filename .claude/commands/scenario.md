Напиши сценарий урока: $ARGUMENTS. Первое слово — номер урока, остальное — необязательные пожелания.

Номер дополни ведущим нулём до двух цифр: результат `scenarios/lesson-NN.md`.

Действуй строго по `docs/scenario-writing.md`: проверки перед началом, чтение
только нужных файлов (без `extras/` и `handouts/`), сценарий, независимая
вычитка, обновление `docs/story.md`, затем краткий отчёт.

`/lesson NN` не запускай: сценарий сначала утверждает автор курса.
